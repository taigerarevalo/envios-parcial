# Parte 1 - Requisitos

## Objetivo
Describir el alcance funcional y no funcional del sistema de gestión de envíos.

## Requisitos funcionales
- Registrar paquetes y destinos.
- Calcular costo estimado por envío.
- Validar datos de entrada.

## Requisitos no funcionales
- Código mantenible.
- Pruebas automatizadas.
- Documentación clara.
