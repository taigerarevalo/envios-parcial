# Envíos Parcial

Proyecto base para la gestión y análisis de envíos, con documentación de requisitos, pruebas, defectos y refactorización.

## Estructura

- `envios.py`: código principal heredado.
- `test_envios.py`: pruebas automatizadas con `pytest`.
- `docs/informe/`: entregables del proceso de análisis y validación.
- `docs/capturas/`: evidencias de pruebas y cobertura.

## Requisitos

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Ejecución

```bash
pytest -q
```
